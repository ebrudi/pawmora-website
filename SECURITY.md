
# Pawmora Security Policy

## Supported Versions

Pawmora is an independently developed cozy pet-life
simulation game currently in active development.

Security updates apply to the latest production version
of the official Pawmora website.

| Version | Supported |
| --- | --- |
| Latest production version | Yes |
| Previous deployments | No |

## Reporting a Vulnerability

If you discover a security vulnerability, please report
it privately through GitHub's vulnerability reporting
system:

https://github.com/ebrudi/pawmora-website/security/advisories/new

Please include:

- A description of the vulnerability.
- The affected page or component.
- Steps to reproduce the issue.
- Potential security impact.
- Relevant screenshots, if applicable.

Do not include passwords, API keys, access tokens,
or personal information in your report.

## Responsible Disclosure

Please do not publicly disclose vulnerabilities before
they have been reviewed and addressed.

Do not perform denial-of-service attacks, destructive
testing, unauthorized data access, or activities that
could disrupt the website or its infrastructure.

## Response Process

As an independent project, Pawmora aims to review
security reports as soon as reasonably possible.

Response and resolution times may vary depending on
the severity and complexity of the issue.

## Bug Bounty

Pawmora does not currently operate a paid bug bounty
program. Financial rewards are not guaranteed.

## Security Commitment

Pawmora aims to protect its users, source code,
infrastructure, and future player data through
responsible security practices and regular reviews.

Thank you for helping keep Pawmora safe.
